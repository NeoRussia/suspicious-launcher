# 0.1.4

The first published build of the Suspicious Speculars installer: a window that puts the
Eclipse-SUSY shader pack, its two resource packs and Demonica into a Cleanroom instance, then hands
the instance back to the launcher it came from.

First release. The installer will keep changing; the shader pack it produces is the settled part.

## What it does

- Runs before the game constructs any mod: a coremod hands over at launch (~5–8 s in) when there is
  work, so the window appears instead of a half-installed game.
- Fetches the Eclipse `e89e6c6` archive from its author when `shaderpacks/` has none, applies the
  22 recorded edits into `Eclipse-SUSY.zip`, and enables it in Demonica's config.
- Installs `Suspicious Speculars` and `Suspicious Speculars - Eclipse Addon` from
  [the pack host](https://github.com/NeoRussia/suspicious-speculars), each verified against its
  SHA-256, and enables both in `options.txt`.
- Fetches Demonica `0.9.1` into `mods/`, but only when Cleanroom is present and no Demonica is there.
- Writes the `SUSY` option set beside a freshly installed shader, generated from the shader's own
  `profile.SUSY` so the two cannot drift.
- Names OptiFine and Nothirium when they are installed, as red lines in the window and a red chat
  line in game, and does nothing else about them — Demonica cannot work beside either.
- Is dormant afterwards: when the recorded state still matches the disk, no window opens and nothing
  is downloaded. A state that promises files which are gone counts as work, not as done.

## Requirements and install

- Cleanroom 0.7.4 or newer (tested on 0.7.14-alpha). The installer itself has no version gate; the
  floor is Demonica's.
- No OptiFine and no Nothirium: both replace machinery Demonica owns.
- Put the jar in `mods/` and launch the instance. The window installs, **Continue** relaunches the
  game. On launchers without an external launch path (CurseForge, the vanilla launcher) the window
  asks for a press of Play instead.

Eclipse is fetched from its author's repository and is not redistributed here. The two resource
packs are downloaded from the project's own host.

## Known limitations

- A pack **update** is announced, not applied behind your back: the window in game says so, and
  *Quit and install* sets it up for the next launch. A pack that is simply missing is repaired by the
  installer before the game starts.
- The window has no progress for the Eclipse download beyond the log; the band shows what was
  fetched when it finishes.
- No CurseForge listing: the installer downloads at install time, which their rules do not allow.
